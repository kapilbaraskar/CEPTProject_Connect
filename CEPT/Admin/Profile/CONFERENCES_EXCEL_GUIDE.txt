✅ EXCEL FEATURE NOW AVAILABLE FOR CONFERENCES!

═══════════════════════════════════════════════════════════════════════════
📥 STEP 1: DOWNLOAD TEMPLATE
═══════════════════════════════════════════════════════════════════════════

1. Open Conferences.aspx page
2. Look for "Excel Import/Export" section (blue header)
3. Click [Download Excel Template] button (green)
4. File downloads: Conferences_Template_YYYYMMDD.xlsx


═══════════════════════════════════════════════════════════════════════════
📋 EXCEL COLUMNS
═══════════════════════════════════════════════════════════════════════════

| Column | Required | Valid Values / Format |
|--------|----------|-----------------------|
| Type | YES ✓ | Conference types from your database |
| Title of Research | YES ✓ | Any text (max 500 chars) |
| Name of Conference | YES ✓ | Any text (max 300 chars) |
| National/International | YES ✓ | National OR International |
| Authorship | YES ✓ | Presenter, Co-Presenter, Attendee, Organizer, Keynote Speaker, Panel Member |
| Submitted to University | YES ✓ | Yes, No, Under Review, Accepted, Rejected |
| Start Date | YES ✓ | YYYY-MM format (e.g., 2024-01) |
| End Date | YES ✓ | YYYY-MM format (e.g., 2024-01) |


═══════════════════════════════════════════════════════════════════════════
📝 STEP 2: FILL EXCEL
═══════════════════════════════════════════════════════════════════════════

EXAMPLE DATA:
┌────────────────────────┬──────────────────────┬───────────────────────┐
│ Type                   │ Title of Research    │ Name of Conference    │
├────────────────────────┼──────────────────────┼───────────────────────┤
│ International Conf     │ AI in Education      │ IEEE ML Conference    │
│ National Conference    │ Deep Learning Apps   │ ACM SIGSOFT Symposium │
└────────────────────────┴──────────────────────┴───────────────────────┘

IMPORTANT RULES:
❗ Delete sample data rows before uploading
❗ Delete instruction rows before uploading
❗ Start filling from Row 2 (after headers)
❗ Use EXACT Conference Type names from your database
❗ Date format must be YYYY-MM (e.g., 2024-01 for January 2024)
❗ End Date must be same as or after Start Date


═══════════════════════════════════════════════════════════════════════════
📤 STEP 3: UPLOAD FILE
═══════════════════════════════════════════════════════════════════════════

1. Save your filled Excel file
2. Return to Conferences.aspx
3. Find "Step 2: Upload Filled Template" (orange section)
4. Click [Choose File]
5. Select your Excel file
6. Click [Upload & Import]

WHAT HAPPENS:
⏳ File uploads
⏳ Data validated
⏳ Conference Types mapped to database codes
⏳ Preview table appears


═══════════════════════════════════════════════════════════════════════════
👁️ STEP 4: PREVIEW DATA
═══════════════════════════════════════════════════════════════════════════

You'll see:
• Blue info box with instructions
• Table showing all your conferences
• Count: "Confirm Import (X conferences)"

REVIEW CHECKLIST:
☑ All rows appear?
☑ No missing data?
☑ Correct Conference Types?
☑ Dates in correct format?


═══════════════════════════════════════════════════════════════════════════
✅ STEP 5: CONFIRM OR CANCEL
═══════════════════════════════════════════════════════════════════════════

OPTION A - CONFIRM:
1. Click [✓ Confirm Import (X conferences)]
2. All conferences added to main table
3. Data automatically saved to database
4. Success message appears
5. ✓ DONE!

OPTION B - CANCEL:
1. Click [✗ Cancel]
2. Preview closes
3. No data imported
4. Start over if needed

🔄 HOW CONFERENCE TYPE MAPPING WORKS
═══════════════════════════════════════════════════════════════════════════

DATABASE:
┌──────────┬────────────────────────┐
│ TypeCode │ TypeName               │
├──────────┼────────────────────────┤
│    1     │ International Conf     │
│    2     │ National Conference    │
│    3     │ Workshop               │
│    4     │ Seminar                │
└──────────┴────────────────────────┘

EXCEL FILE (What you type):
Type: "International Conf"

SYSTEM AUTOMATICALLY MAPS:
"International Conf" → TypeCode "1"

DATABASE RECEIVES:
TypeCode = "1" ✓ (Correct!)


═══════════════════════════════════════════════════════════════════════════
✅ VALIDATION EXAMPLES
═══════════════════════════════════════════════════════════════════════════

VALID (Will Import):
────────────────────────────────────────────────────────────────────────────
"International Conference" → ✓ Maps to database code
"National Conference" → ✓ Maps to database code
"international conference" → ✓ Case-insensitive match
"2024-01" → ✓ Valid date format


INVALID (Will Skip):
────────────────────────────────────────────────────────────────────────────
"Magazine Conference" → ✗ Not in database
"Jan 2024" → ✗ Wrong date format (use 2024-01)
"2024-13" → ✗ Invalid month (13)
End Date before Start Date → ✗ Invalid date range


═══════════════════════════════════════════════════════════════════════════
⚠️ COMMON ERRORS & FIXES
═══════════════════════════════════════════════════════════════════════════

ERROR: "Please select an Excel file first!"
FIX: Click "Choose File" before "Upload & Import"

ERROR: "Excel file is empty or has no data rows!"
FIX: Add data starting from Row 2

ERROR: "No valid data found in Excel file!"
FIX: 
  • Check all required fields are filled
  • Verify Conference Type spelling
  • Check date format (YYYY-MM)

ERROR: "Skipping row X: Invalid Conference Type"
FIX:
  • Download fresh template (has correct types)
  • Copy Conference Type exactly from sample data
  • Check spelling

ERROR: "Skipping row X: Missing required fields"
FIX: Fill all 8 required columns

ERROR: Some rows missing after import
FIX: Those rows had validation errors - check console (F12)

💡 PRO TIPS
═══════════════════════════════════════════════════════════════════════════

TIP 1: Copy from Sample Data
→ Sample rows have exact Conference Type spellings
→ Copy-paste to avoid typos

TIP 2: Download Fresh Template
→ Template always shows current valid types from database
→ If admin adds new type, download new template

TIP 3: Date Format is Critical
→ Must be YYYY-MM format
→ Examples: 2024-01, 2024-12, 2023-06
→ Invalid: Jan 2024, 01-2024, 2024/01

TIP 4: Check Browser Console
→ Press F12 to see debugging info
→ Shows which Conference Types are available
→ Shows which rows are skipped and why

TIP 5: Case Doesn't Matter for Type
→ "International Conference" = "international conference"
→ System handles case-insensitive matching

TIP 6: Multiple Conferences at Once
→ Add as many rows as you need
→ All imported together in one operation

📝 FIELD NOTES
═══════════════════════════════════════════════════════════════════════════

TYPE:
• Must match database Conference Type EXACTLY
• Case-insensitive ("Workshop" = "workshop")
• Check template instructions for available types

TITLE OF RESEARCH:
• Max 500 characters
• Can include punctuation
• Required field

NAME OF CONFERENCE:
• Max 300 characters
• Full official name of conference
• Required field

NATIONAL/INTERNATIONAL:
• Only two options: "National" or "International"
• Case-insensitive

AUTHORSHIP:
• Presenter - You presented the paper
• Co-Presenter - Joint presentation
• Attendee - Attended only
• Organizer - Helped organize
• Keynote Speaker - Main speaker
• Panel Member - Panel discussion

SUBMITTED TO UNIVERSITY:
• Yes - Submitted and credited
• No - Not submitted
• Under Review - Currently reviewing
• Accepted - Accepted by university
• Rejected - Not accepted

DATES:
• Format: YYYY-MM
• Start Date: When conference started
• End Date: When conference ended
• End must be >= Start
