                    HOW TO USE THE EXCEL FEATURE
                        Publications Page
═══════════════════════════════════════════════════════════════════════════

✅ FEATURE NOW IMPLEMENTED AND READY TO USE!

═══════════════════════════════════════════════════════════════════════════
📥 STEP 1: DOWNLOAD TEMPLATE
═══════════════════════════════════════════════════════════════════════════

1. Open Publication.aspx page
2. Look for the "Excel Import/Export" section (blue header with Excel icon)
3. Click the [Download Excel Template] button (green button)
4. File will download: Publications_Template_YYYYMMDD.xlsx

WHAT YOU GET:
✓ 12 pre-formatted columns
✓ 2 sample data rows
✓ Detailed instructions in the file
✓ Ready to fill and upload


═══════════════════════════════════════════════════════════════════════════
📝 STEP 2: FILL THE TEMPLATE
═══════════════════════════════════════════════════════════════════════════

COLUMNS IN ORDER:
1. Publication Type       (Required) - Journal Article, Conference Paper, etc.
2. Journal/Conference Name (Required) - Name of journal or conference
3. Title of Research      (Required) - Full title
4. Scope                  - National or International
5. Impact Factor          - Number or N/A
6. Authorship            - First Author, Co-Author, etc.
7. Author Details        - Comma-separated names
8. Month of Publication  - January to December
9. Year of Publication   - 2020-2025
10. Submitted to University - Yes or No
11. Publication Status   - Published, Accepted, Under Review, etc.
12. Total Hours          - Number (default 0)

IMPORTANT:
❗ Fill data starting from Row 2 (after headers)
❗ Delete the sample data rows before uploading
❗ Delete instruction rows
❗ Required fields: Publication Type, Journal/Conference Name, Title
❗ Save file after filling


═══════════════════════════════════════════════════════════════════════════
📤 STEP 3: UPLOAD THE FILE
═══════════════════════════════════════════════════════════════════════════

1. Return to Publication.aspx page
2. Find "Step 2: Upload Filled Template" (orange section)
3. Click [Choose File] button
4. Select your filled Excel file (.xlsx or .xls)
5. Click [Upload & Import] button

WHAT HAPPENS:
⏳ File uploads and parses
⏳ Data is validated
⏳ Invalid rows filtered out
✓ Preview table appears


═══════════════════════════════════════════════════════════════════════════
👁️ STEP 4: PREVIEW YOUR DATA
═══════════════════════════════════════════════════════════════════════════

You'll see:
• Blue info box: "Preview: Review the imported data below..."
• Table showing ALL your publications
• Count: "Confirm Import (X publications)"

REVIEW:
☑ Check all rows appear correctly
☑ Verify no missing data
☑ Hover over truncated text to see full content


═══════════════════════════════════════════════════════════════════════════
✅ STEP 5: CONFIRM OR CANCEL
═══════════════════════════════════════════════════════════════════════════

OPTION A - CONFIRM:
1. Click [✓ Confirm Import (X publications)] green button
2. All publications added to main table
3. Data automatically saved to database
4. Success message appears
5. Preview closes
6. DONE! Your publications are saved

OPTION B - CANCEL:
1. Click [✗ Cancel] gray button
2. Preview closes
3. No data imported
4. File selection cleared
5. Start over if needed

⚠️ COMMON ERRORS & FIXES
═══════════════════════════════════════════════════════════════════════════

ERROR: "Please select an Excel file first!"
FIX: Click "Choose File" button before "Upload & Import"

ERROR: "Excel file is empty or has no data rows!"
FIX: Make sure you added data starting from Row 2

ERROR: "No valid data found in Excel file!"
FIX: Check that required fields are filled:
     - Publication Type
     - Journal/Conference Name
     - Title of Research

ERROR: Some rows missing in preview
FIX: Those rows were missing required fields - check and re-upload

ERROR: File won't upload
FIX: 
  • Use only .xlsx or .xls format
  • Close Excel before uploading
  • Re-save the file
