📥 STEP 1: DOWNLOAD TEMPLATE
═══════════════════════════════════════════════════════════════════════════

1. Open Research.aspx page
2. Look for "Excel Import/Export" section (blue header)
3. Click [Download Excel Template] button (green)
4. File downloads: Research_Projects_Template_YYYYMMDD.xlsx

📋 EXCEL COLUMNS (9 Columns Total)
═══════════════════════════════════════════════════════════════════════════

| Column | Required | Valid Values / Format |
|--------|----------|-----------------------|
| Type | YES ✓ | Research types from your database |
| Title | YES ✓ | Any text (max 200 chars) |
| Status | YES ✓ | Proposed, Under Review, Approved, In Progress, Completed, On Hold, Cancelled |
| Description | YES ✓ | Any text (max 1000 chars) |

| Fund Available | No | Number or text |
| Duration | No | e.g., "2 years", "18 months" |
| Start Date | YES ✓ | YYYY-MM format (e.g., 2024-01) |
| End Date | YES ✓ | YYYY-MM format (e.g., 2025-12) |

IMPORTANT RULES:

6. Click [Upload & Import]

WHAT HAPPENS:

⏳ Data validated
⏳ Research Types mapped to database codes
⏳ Preview table appears

⚠️ COMMON ERRORS & FIXES
═══════════════════════════════════════════════════════════════════════════

ERROR: "Please select an Excel file first!"
FIX: Click "Choose File" before "Upload & Import"

ERROR: "Excel file is empty or has no data rows!"
FIX: Add data starting from Row 2

ERROR: "No valid data found in Excel file!"
FIX: 
  • Check all required fields are filled (6 required columns)
  • Verify Research Type spelling
  • Check date format (YYYY-MM)
  • Ensure Status is valid

ERROR: "Skipping row X: Invalid Research Type"
FIX:
  • Download fresh template (has correct types)
  • Copy Research Type exactly from sample data
  • Check spelling

ERROR: "Skipping row X: Missing required fields"
FIX: Fill all 6 required columns:
     - Type
     - Title
     - Status
     - Description
     - Start Date
     - End Date

ERROR: Some rows missing after import
FIX: Those rows had validation errors - check console (F12)

📝 FIELD DETAILS
═══════════════════════════════════════════════════════════════════════════

TYPE:
• Must match database Research Type EXACTLY
• Case-insensitive ("Basic Research" = "basic research")
• Check template instructions for available types

TITLE:
• Max 200 characters
• Brief project name
• Required field

STATUS:
• Only 7 valid options (see list above)
• Case-sensitive recommended
• Required field

DESCRIPTION:
• Max 1000 characters
• Detailed project description
• Required field
• Explain project goals, methodology, outcomes

FUNDING AGENCY:
• Optional
• Max 150 characters
• Name of funding organization

FUND AVAILABLE:
• Optional
• Can be number or text
• Example: "500000" or "5 Lakhs"

DURATION:
• Optional
• Free-form text
• Example: "2 years", "18 months", "Jan 2024 - Dec 2025"

DATES:
• Format: YYYY-MM
• Start Date: When project started/starts
• End Date: When project ends/ended
• End must be >= Start
• Both required
