═══════════════════════════════════════════════════════════════════════════

🔍 PROBLEM: Document name not saving to database

This guide will help you debug and fix the issue.

═══════════════════════════════════════════════════════════════════════════
📋 STEP 1: CHECK BROWSER CONSOLE (MOST IMPORTANT!)
═══════════════════════════════════════════════════════════════════════════

1. Open your browser (Chrome/Edge/Firefox)
2. Press F12 to open Developer Tools
3. Click on the "Console" tab
4. Clear the console (click the 🚫 icon)
5. Now perform the following actions:

ACTION A - UPLOAD A FILE:
──────────────────────────────────────────────────────────────────────────
1. Select a file (PDF/DOC/image)
2. Look for these console messages:

   === Uploading File to Server ===
   File name: experience_certificate.pdf
   File size: 245632
   Document type: ExperienceDocuments
   Upload response received: {"fileName":"exp_20241015_123456.pdf","error":""}
   Response type: object
   Parsed result: {fileName: "exp_20241015_123456.pdf", error: ""}
   ✓ Upload successful! File name: exp_20241015_123456.pdf

EXPECTED OUTPUT:
✓ Upload successful! File name: [some file name]

POSSIBLE ISSUES:
✗ If you see "✗ Upload failed:" - Check UserUploadFile.ashx handler
✗ If you see "✗ File upload AJAX error:" - Check file path or permissions
✗ If response is empty - Handler is not returning data correctly


ACTION B - ADD EXPERIENCE RECORD:
──────────────────────────────────────────────────────────────────────────
1. Fill in all required fields
2. Click "Add Experience"
3. Look for these console messages:

   Adding experience record with document: exp_20241015_123456.pdf
   Experience Data: {
       organization_name: "ABC Company",
       designation: "Software Engineer",
       experience_type: "Industry",
       ...
       experienced_document_ref: "exp_20241015_123456.pdf",
       id: 1697384723456
   }

EXPECTED OUTPUT:
✓ experienced_document_ref should have a value (not null)

POSSIBLE ISSUES:
✗ If experienced_document_ref is null - File upload failed or wasn't completed
✗ If experienced_document_ref is "Upload failed" - Check upload handler


ACTION C - SAVE TO DATABASE:
──────────────────────────────────────────────────────────────────────────
1. Click "Save All" button
2. Look for these console messages:

   === Saving Experience Records to Database ===
   Number of records: 1
   Experience Records Data: [{...}]
   Record 0 document: exp_20241015_123456.pdf
   JSON Data being sent: {"formDataJson":"[{\"organization_name\":\"ABC\"...\"experienced_document_ref\":\"exp_20241015_123456.pdf\"...}]"}

EXPECTED OUTPUT:
✓ Record X document should show the file name
✓ JSON Data should include "experienced_document_ref":"filename.pdf"

POSSIBLE ISSUES:
✗ If document is null - File wasn't properly added to the record
✗ If JSON doesn't include experienced_document_ref - Data structure issue


═══════════════════════════════════════════════════════════════════════════
🔧 STEP 2: CHECK WEB SERVICE (BACKEND)
═══════════════════════════════════════════════════════════════════════════

The frontend is sending the document name correctly if you see it in the console.
Now check the backend:

FILE: WebService.asmx.cs or WebService.asmx
METHOD: SaveExperienceDetails

CHECK THESE:
──────────────────────────────────────────────────────────────────────────
1. Does the method receive the 'experienced_document_ref' field?
   
   Example C# code:
   ```csharp
   public class ExperienceDetail
   {
       public string organization_name { get; set; }
       public string designation { get; set; }
       public string experience_type { get; set; }
       public string start_date { get; set; }
       public string end_date { get; set; }
       public string mode_of_experience { get; set; }
       public string total_hours_in_week { get; set; }
       public string total_year_months_counts { get; set; }
       public string experienced_document_ref { get; set; }  // ← CHECK THIS!
       public long id { get; set; }
   }
   ```

2. Is the field being saved to the database?
   
   Check SQL INSERT/UPDATE statement includes this field:
   ```sql
   INSERT INTO ExperienceDetails (
       organization_name,
       designation,
       ...
       experienced_document_ref  -- ← MUST BE HERE!
   ) VALUES (...)
   ```

3. Does the database column exist?
   
   TABLE: ExperienceDetails (or similar)
   COLUMN: experienced_document_ref (VARCHAR/NVARCHAR)

🔍 STEP 3: COMMON ISSUES & FIXES
═══════════════════════════════════════════════════════════════════════════

ISSUE 1: File uploads but document is null when adding record
──────────────────────────────────────────────────────────────────────────
CAUSE: Upload completes but currentUploadedFile variable not set
FIX: Check these console logs:
     - "✓ Upload successful! File name: [filename]"
     - "Adding experience record with document: [filename]"
     
     If first shows filename but second is null:
     → File upload callback not setting currentUploadedFile
     → Check uploadFileToServer function callback


ISSUE 2: Document shows in table but not saved to database
──────────────────────────────────────────────────────────────────────────
CAUSE: Frontend has data but backend doesn't save it
FIX: 
1. Check console: "Record 0 document: [filename]"
2. If filename shows in console but not in database:
   → Backend model missing 'experienced_document_ref' property
   → SQL query missing 'experienced_document_ref' column
   → Database table missing column


ISSUE 3: Upload shows "Upload failed"
──────────────────────────────────────────────────────────────────────────
CAUSE: UserUploadFile.ashx handler error
FIX:
1. Check handler path: ../../Handler/UserUploadFile.ashx
2. Check handler accepts 'file' and 'documentType' parameters
3. Check folder 'ExperienceDocuments' exists and has write permissions
4. Check handler returns correct JSON:
   {"fileName":"uploaded_file_name.pdf","error":""}


ISSUE 4: File name has wrong path in database
──────────────────────────────────────────────────────────────────────────
CAUSE: Handler returns full path instead of just filename
FIX: Handler should return only the filename, not full path
     
     WRONG: "C:\Uploads\ExperienceDocuments\file.pdf"
     RIGHT: "file.pdf"
     
     OR if using subfolders:
     RIGHT: "ExperienceDocuments/file.pdf"
