═══════════════════════════════════════════════════════════════════════════
⚠️ COMMON ERRORS & FIXES
═══════════════════════════════════════════════════════════════════════════

ERROR: "Please select an Excel file first!"
FIX: Click "Choose File" before "Upload & Import"

ERROR: "Excel file is empty or has no data rows!"
FIX: Add data starting from Row 2

ERROR: "No valid data found in Excel file!"
FIX: 
  • Check all required fields are filled (6 required columns)
  • Verify Research Activity Type spelling
  • Check date format (YYYY-MM-DD)
  • Verify Total Hours is valid number
  • Check Year is valid

ERROR: "Skipping row X: Invalid Research Type"
FIX:
  • Download fresh template (has correct types)
  • Copy Research Activity Type exactly from sample data
  • Check spelling

ERROR: "Skipping row X: Invalid Year"
FIX:
  • Download fresh template (has correct years)
  • Copy Year exactly from sample data
  • Check year format

ERROR: "Skipping row X: Invalid Total Hours"
FIX:
  • Total Hours must be number between 1-9999
  • Examples: 10, 50, 100, 500
  • Not: 0, -5, "ten", 10000

ERROR: "Skipping row X: Missing required fields"
FIX: Fill all 6 required columns:
     - Title
     - Type
     - Description
     - Total Hours
     - Date
     - Year

ERROR: Some rows missing after import
FIX: Those rows had validation errors - check console (F12)

💡 PRO TIPS
═══════════════════════════════════════════════════════════════════════════

TIP 1: Copy from Sample Data
→ Sample rows have exact Research Activity Type spellings
→ Sample rows have exact Year values
→ Copy-paste to avoid typos

TIP 2: Download Fresh Template
→ Template always shows current valid types from database
→ Template always shows current valid years from database
→ If admin adds new type/year, download new template

TIP 3: Date Format is Critical
→ Must be YYYY-MM-DD format
→ Examples: 2024-01-15, 2024-12-31, 2023-06-10
→ Invalid: Jan 15 2024, 15-01-2024, 2024/01/15

TIP 4: Total Hours Validation
→ Must be whole number
→ Range: 1 to 9999
→ Examples: 1, 10, 50, 100, 500, 1000
→ Invalid: 0, -5, 0.5, "fifty", 10000

TIP 5: All Fields Required
→ No optional fields in this form
→ All 6 columns must have values
→ Empty cells cause row to be skipped

TIP 6: Check Browser Console
→ Press F12 to see debugging info
→ Shows which Research Activity Types are available
→ Shows which Years are available
→ Shows which rows are skipped and why

TIP 7: Multiple Activities at Once
→ Add as many rows as you need
→ All imported together in one operation
