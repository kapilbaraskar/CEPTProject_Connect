🔄 HOW FILTERING WORKS
═══════════════════════════════════════════════════════════════════════════

EXAMPLE: Filter by "2024-2025"
──────────────────────────────────────────────────────────────────────────
BEFORE (All Years):
• Publications: 15 total
• Conferences: 8 total
• Research: 5 total

AFTER (2024-2025 only):
• Publications: 6 (only 2024-2025)
• Conferences: 3 (only 2024-2025)
• Research: 2 (only 2024-2025)

FILTERING LOGIC:
──────────────────────────────────────────────────────────────────────────
Publications:
  ✓ Checks publication_date field
  ✓ Checks year field
  ✓ Matches if date contains "2024"

Conferences:
  ✓ Checks start_date field
  ✓ Checks year field
  ✓ Matches if date contains "2024"

Research Projects:
  ✓ Server-side filtering via yearcode parameter
  ✓ WebService handles the filtering

Other Research Activities:
  ✓ Checks year field
  ✓ Checks date field
  ✓ Exact year match or date contains year

Experience Details:
  ✓ Checks if employment period overlaps with selected year
  ✓ Example: Job from 2023-2025 shows in 2024-2025 filter

🎯 FILTERING LOGIC DETAILS
═══════════════════════════════════════════════════════════════════════════

PUBLICATIONS FILTERING:
──────────────────────────────────────────────────────────────────────────
Checks:
1. publication_date field contains year (e.g., "2024")
2. year field matches yearcode (e.g., "2024-2025")

Example:
• Publication Date: "2024-03-15"
• Filter: "2024-2025"
• Result: ✓ Match (date contains "2024")


CONFERENCES FILTERING:
──────────────────────────────────────────────────────────────────────────
Checks:
1. start_date, date, or end_date contains year
2. year field matches yearcode

Example:
• Conference Date: "2024-01-20"
• Filter: "2024-2025"
• Result: ✓ Match (date contains "2024")


RESEARCH PROJECTS FILTERING:
──────────────────────────────────────────────────────────────────────────
Server-side filtering:
• Sends yearcode parameter to WebService
• Backend filters data
• Only matching records returned

Example:
• Research Year: "2024-2025"
• Filter: "2024-2025"
• Result: ✓ Match (exact match)


OTHER RESEARCH ACTIVITIES FILTERING:
──────────────────────────────────────────────────────────────────────────
Checks:
1. year field matches yearcode (exact)
2. date field contains year

Example:
• Activity Year: "2024-2025"
• Filter: "2024-2025"
• Result: ✓ Match (exact match)


EXPERIENCE DETAILS FILTERING:
──────────────────────────────────────────────────────────────────────────
Advanced logic:
• Checks if employment period overlaps with selected academic year
• If Start ≤ SelectedYear AND End ≥ SelectedYear → Match

Example:
• Job Period: 2023-01-01 to 2025-12-31
• Filter: "2024-2025" (year 2024)
• Start Year: 2023 ≤ 2024 ✓
• End Year: 2025 ≥ 2024 ✓
• Result: ✓ Match (overlaps)

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

ISSUE: No data appears
──────────────────────────────────────────────────────────────────────────
FIX:
1. Check browser console (F12) for errors
2. Verify WebService methods are accessible
3. Check if data exists in other pages
4. Click [Refresh All Data]


ISSUE: Year filter doesn't work
──────────────────────────────────────────────────────────────────────────
FIX:
1. Ensure year field is populated in source pages
2. Check console for JavaScript errors
3. Try [Show All Years] then reapply filter


ISSUE: Stats show 0 but data is in table
──────────────────────────────────────────────────────────────────────────
FIX:
1. Refresh the page
2. Stats update based on filtered data
3. If persists, check console for errors


ISSUE: Some records missing after filter
──────────────────────────────────────────────────────────────────────────
EXPLANATION:
This is normal - records without matching year/date are filtered out
• Check if record has year/date field populated
• Try "All Years" to see all records
