            PUBLICATION TYPE MAPPING - TECHNICAL GUIDE
                    Excel Import Feature
═══════════════════════════════════════════════════════════════════════════

📋 OVERVIEW
═══════════════════════════════════════════════════════════════════════════

The Excel import feature now includes AUTOMATIC MAPPING between:
• Publication Type NAMES (shown in Excel) 
• Publication Type CODES (stored in database)

This ensures Excel data is correctly saved to the database with proper TypeCode values.


═══════════════════════════════════════════════════════════════════════════
🔄 HOW THE MAPPING WORKS
═══════════════════════════════════════════════════════════════════════════

STEP 1: Load Publication Types from Database
────────────────────────────────────────────────────────────────────────────
When page loads:
→ Calls: WebService.asmx/GetPublicationType
→ Receives: Array of {TypeCode, TypeName} objects
→ Example: 
  {
    "TypeCode": "1",
    "TypeName": "Journal Article"
  },
  {
    "TypeCode": "2",
    "TypeName": "Conference Paper"
  }

STEP 2: Build Mapping Dictionary
────────────────────────────────────────────────────────────────────────────
→ Stores in JavaScript object: publicationTypesMapping
→ Format: { "TypeName": "TypeCode" }
→ Example:
  {
    "Journal Article": "1",
    "Conference Paper": "2",
    "Book Chapter": "3",
    "Book": "4",
    "Patent": "5",
    "Technical Report": "6"
  }

STEP 3: Excel Template Generation
────────────────────────────────────────────────────────────────────────────
When user clicks "Download Excel Template":
→ Reads available types from dropdown
→ Uses actual TypeNames from database
→ Sample data shows valid Publication Types
→ Instructions list all available types

STEP 4: Excel Import & Mapping
────────────────────────────────────────────────────────────────────────────
When user uploads Excel file:
→ Reads "Publication Type" column value (e.g., "Journal Article")
→ Looks up in publicationTypesMapping
→ Finds TypeCode (e.g., "1")
→ Stores both in record:
  • publication_type: "1" (TypeCode - for database)
  • publication_type_name: "Journal Article" (TypeName - for display)

STEP 5: Save to Database
────────────────────────────────────────────────────────────────────────────
When saving:
→ Uses publication_type (TypeCode) field
→ Database receives correct code value
→ ✓ Data saved successfully!


═══════════════════════════════════════════════════════════════════════════
💻 CODE IMPLEMENTATION
═══════════════════════════════════════════════════════════════════════════

GLOBAL VARIABLE:
────────────────────────────────────────────────────────────────────────────
var publicationTypesMapping = {}; // Stores TypeName -> TypeCode mapping


LOADING TYPES (loadPublicationsType function):
────────────────────────────────────────────────────────────────────────────
$.each(result, function (index, item) {
    var typeCode = item.TypeCode;
    var typeName = item.TypeName;
    
    // Add to dropdown
    $('#publication_type').append(
        $('<option></option>')
            .attr('value', typeCode)
            .text(typeName)
    );
    
    // Store mapping for Excel import
    publicationTypesMapping[typeName] = typeCode;
});


EXCEL PARSING (parseExcelData function):
────────────────────────────────────────────────────────────────────────────
// Get Publication Type from Excel
var publicationType = row[0].toString().trim(); // e.g., "Journal Article"

// Map to database TypeCode
var publicationTypeCode = publicationTypesMapping[publicationType];

// Case-insensitive fallback
if (!publicationTypeCode) {
    for (var typeName in publicationTypesMapping) {
        if (typeName.toLowerCase() === publicationType.toLowerCase()) {
            publicationTypeCode = publicationTypesMapping[typeName];
            publicationType = typeName;
            break;
        }
    }
}

// Validation - skip if invalid type
if (!publicationTypeCode) {
    console.warn('Invalid Publication Type: ' + publicationType);
    continue; // Skip this row
}

// Create record with both TypeCode and TypeName
var publicationData = {
    publication_type: publicationTypeCode,        // "1" (for database)
    publication_type_name: publicationType,       // "Journal Article" (for display)
    // ... other fields
};


═══════════════════════════════════════════════════════════════════════════
✅ VALIDATION & ERROR HANDLING
═══════════════════════════════════════════════════════════════════════════

EXACT MATCH:
────────────────────────────────────────────────────────────────────────────
Excel: "Journal Article"
Mapping: { "Journal Article": "1" }
Result: ✓ Found! TypeCode = "1"


CASE-INSENSITIVE MATCH:
────────────────────────────────────────────────────────────────────────────
Excel: "journal article" (lowercase)
Mapping: { "Journal Article": "1" }
Result: ✓ Found! TypeCode = "1" (case-insensitive search)


INVALID TYPE:
────────────────────────────────────────────────────────────────────────────
Excel: "Magazine Article"
Mapping: { "Journal Article": "1", "Conference Paper": "2" }
Result: ✗ Not found! Row skipped with warning in console


CONSOLE OUTPUT:
────────────────────────────────────────────────────────────────────────────
When uploading Excel:
> Available Publication Types Mapping: { "Journal Article": "1", ... }
> Skipping row 5: Invalid Publication Type "Magazine Article"

COMMON ISSUES:
────────────────────────────────────────────────────────────────────────────

ISSUE: "Skipping row X: Invalid Publication Type"
CAUSE: Excel contains type name not in database
FIX: 
  • Download fresh template (has correct types)
  • Or add type to database first
  • Or fix spelling in Excel


ISSUE: Empty publicationTypesMapping object
CAUSE: Publication types not loaded from database
FIX:
  • Check WebService.asmx is running
  • Check GetPublicationType method exists
  • Check database connection
  • Look for errors in browser console


ISSUE: TypeCode showing in display instead of TypeName
CAUSE: publication_type_name not set correctly
FIX: Check parseExcelData() sets both fields correctly

📝 MAINTENANCE NOTES
═══════════════════════════════════════════════════════════════════════════

When adding NEW Publication Types to database:
1. Add to PublicationType table
2. No code changes needed
3. Mapping updates automatically on page load

When RENAMING Publication Types:
1. Update TypeName in database
2. Old Excel files with old name will fail
3. Users need to download fresh template

When REMOVING Publication Types:
1. Remove from database
2. Existing records with that type remain
3. New imports cannot use removed type
