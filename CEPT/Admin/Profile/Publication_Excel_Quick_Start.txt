📥 STEP 1: DOWNLOAD EXCEL TEMPLATE
═══════════════════════════════════════════════════════════════════════════

1. Open Publication.aspx page
2. Look for "Excel Import/Export" section
3. Click [Download Excel Template] button
4. Excel file will download: Publications_Template_YYYYMMDD.xlsx

TEMPLATE INCLUDES:
✓ All 12 required columns with headers
✓ 2 sample data rows (for reference)
✓ Detailed instructions
✓ Pre-formatted columns

📤 STEP 3: UPLOAD FILLED EXCEL FILE
═══════════════════════════════════════════════════════════════════════════

1. Save your Excel file
2. Return to Publication.aspx page
3. Look for "Step 2: Upload Filled Template" section
4. Click [Choose File] button
5. Select your filled Excel file
6. Click [Upload & Import] button

WHAT HAPPENS:
⏳ File is uploaded
⏳ Data is parsed and validated
⏳ Invalid rows are filtered out
✓ Preview table is displayed

═══════════════════════════════════════════════════════════════════════════

⚠️ COMMON ERRORS & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════

ERROR: "Please select an Excel file first!"
SOLUTION: Click "Choose File" before "Upload & Import"

ERROR: "Excel file is empty or has no data rows!"
SOLUTION: 
  - Add data starting from Row 2
  - Make sure you saved the file

ERROR: "No valid data found in Excel file!"
SOLUTION:
  - Check all required fields are filled
  - Remove instruction rows
  - Verify column headers match template

ERROR: "Error parsing Excel file"
SOLUTION:
  - Use .xlsx or .xls format only
  - Re-save file in Excel
  - Try downloading fresh template

ERROR: Some rows missing after import
SOLUTION:
  - Those rows had missing required fields
  - Check Publication Type, Journal Name, and Title
  - Re-upload with complete data

🔍 VALIDATION RULES
═══════════════════════════════════════════════════════════════════════════

AUTOMATIC VALIDATIONS:
✓ Empty rows are skipped
✓ Instruction rows are filtered out
✓ Required fields must have values
✓ Invalid rows are excluded

WHAT GETS IMPORTED:
✓ Rows with all 3 required fields:
  1. Publication Type
  2. Journal/Conference Name
  3. Title of Research

WHAT GETS SKIPPED:
✗ Completely empty rows
✗ Rows with "Instructions" text
✗ Rows missing required fields
✗ Header row
